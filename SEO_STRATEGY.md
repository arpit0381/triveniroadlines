## 6. Execution Checklists

### Technical SEO Checklist
- [ ] Implement `robots.txt` and `sitemap.xml`.
- [ ] Install `react-helmet-async` (if using React SPA) to manage dynamic `<title>`, `<meta>`, and `<link rel="canonical">` tags.
- [ ] Set up Open Graph (`og:title`, `og:image`) and Twitter Card tags.
- [ ] Ensure HTTPS is enforced.
- [ ] Configure proper 404 error page.
- [ ] Implement Lazy Loading for images (`loading="lazy"`).
- [ ] Inject JSON-LD Structured Data into the `<head>`.
- [ ] Implement semantic HTML5 (`<header>`, `<main>`, `<article>`, `<section>`, `<footer>`).

### Performance Checklist
- [ ] Compress and convert images to WebP/AVIF format.
- [ ] Set explicit `width` and `height` attributes on all images to prevent CLS (Cumulative Layout Shift).
- [ ] Minify CSS and JS bundles.
- [ ] Preconnect to critical domains (e.g., Google Fonts).
- [ ] Enable GZIP/Brotli compression on the server.
- [ ] Target: LCP < 2.5s, CLS < 0.1.

### Local SEO & Citations Checklist
- [ ] Create/Claim Google Business Profile (GBP) for "Triveni Road Lines".
- [ ] Ensure NAP (Name, Address, Phone) consistency across the website footer and contact page.
- [ ] Embed a Google Map of the Chakarpur Mandi location on the Contact and Location pages.
- [ ] List business on Justdial, IndiaMART, Sulekha, TradeIndia, and ExportersIndia.
- [ ] Build a review acquisition strategy (e.g., sending SMS with review link after successful delivery).

### Analytics & Search Console Setup
- [ ] Verify domain ownership in Google Search Console via DNS or HTML tag.
- [ ] Submit `sitemap.xml` to Search Console.
- [ ] Set up Google Analytics 4 (GA4) property.
- [ ] Configure GA4 custom events for: 
  - Phone Number Clicks (`tel:`)
  - Email Clicks (`mailto:`)
  - Form Submissions (Quote Request)

### Conversion Rate Optimization (CRO)
- [ ] Add a sticky "Call Now" and "WhatsApp" floating button on mobile.
- [ ] Include clear Call-to-Action (CTA) banners on every service page.
- [ ] Place trust badges (e.g., "15+ Years Experience", "24/7 Support", "GPS Tracking") near CTAs.
- [ ] Implement an easy-to-use "Get a Quote" form on the homepage and contact page.
